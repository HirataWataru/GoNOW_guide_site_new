運用に最低限必要な設定を、次の順番で行います。このページは **1. 初期設定** です。

1. **初期設定**：会社・支社・営業所・配送員など、配送する側を登録する（このページ）
2. **[顧客登録](/articles/phase2-customer-registration)**：配送先の住所・タンク・センサーを登録する
3. **[基本操作トレーニング](/articles/phase3-training)**：配送シーズン前に操作に慣れる

## 1. ログインする

初回のログイン情報はメールでお送りします。ブラウザで [GoNOW（https://app2.5-now.com/login）](https://app2.5-now.com/login)を開きます。

**初回**は、メールでお知らせした**会社コード・ユーザーコード・パスワード**を入力してログインします。

![ログイン画面（会社コード・ユーザーコード・パスワードを入力）](/images/articles/setup/login-code.png)

メールアドレスでユーザー登録をすると（[手順](#2-ユーザーを登録する)）、次回から**メールアドレスとパスワード**でもログインできます。画面下の「会社コード/ユーザーコードを使用⇒」「メールアドレスを使用⇒」で切り替えます。

![メールアドレスでのログイン画面](/images/articles/setup/login-email.png)

### 画面の見方

日々の運用で使うのは、左の**サイドバー**です。

![ログイン後の画面とサイドバー](/images/articles/setup/sidebar.png)

| メニュー | できること |
| --- | --- |
| 配送計画 | 配送予定の確認・調整。日々の配送に使う画面 |
| 顧客 | 配送先の登録・管理 |
| グループ | グループ／エリア／ユーザーの登録・変更 |
| データ入出力 | 顧客情報・給油情報の一括入力／出力（THE灯油・雪ん子との連携も可） |
| タンク一覧 | 登録できるタンクタイプの一覧 |
| アラート | 注意や確認が必要な内容 |

## 2. ユーザーを登録する

GoNOW を使う人が2名以上いる場合は、ユーザーを追加します。登録数に制限はありません。

1. サイドバーの **【グループ】** をクリック
2. 右上の **【ユーザー登録】** をクリック
3. ユーザーの情報を入力して **【登録】**

| ログイン方法 | 入力が必須の項目 |
| --- | --- |
| ユーザーコードでログインする | 名称・**ユーザーコード**・所属・役割・パスワード |
| メールアドレスでログインする | 名称・**メールアドレス**・所属・役割・パスワード |

> [!NOTE]
> - パスワードは **12文字以上**で、半角の英大文字・英小文字・数字・記号のうち **3種類以上**を含めてください。
> - **アラートメールを受け取る**ユーザーは、メールアドレスで登録してください。

![ユーザー登録画面](/images/articles/setup/user-register-email.png)

<details>
<summary>パスワードの初期化・ユーザー情報の変更・削除</summary>

サイドバーの【グループ】→ 右下のユーザー一覧から対象のユーザーをクリックし、**【パスワードの初期化】** または **【登録内容変更】** を選びます。登録内容変更の画面から、名称・所属・役割の変更や、ユーザーの削除ができます。

![ユーザーの詳細画面](/images/articles/setup/user-edit.png)

</details>

## 3. グループ／エリアを登録する

GoNOW は **カンパニー（会社）→ グループ（支社・営業所）→ エリア（配送の単位）** の3階層で管理し、階層ごとに権限を分けられます。

![管理者の種類と組織図](/images/articles/setup/roles.png)

| 管理者 | 役割 | できること |
| --- | --- | --- |
| システム管理者 | GoNOW 全体の責任者 | すべての機能。データ入出力での一括編集・削除、各管理者の設定 |
| グループ管理者 | 配送拠点・計画を監督する事業責任者 | 所属グループ以下の閲覧・登録・変更、管理者の設定 |
| エリア管理者 | 配送を行う現場責任者 | 所属エリアだけの閲覧・登録・変更（モバイルでの利用を想定） |

- **グループ**：支社・支店・営業所など、配下に配送エリアを持つ単位。グループの下にグループも作れます。支社などがなければ登録は不要です
- **エリア**：配送の最小単位（エリア名・配送車名・配送員名など）。**顧客はエリアごとに配送計画が作られます**

### 登録のしかた

1. サイドバーの **【グループ】** → 右上の **【グループ/エリア登録】** をクリック
2. 種別で **「グループ」** か **「エリア」** を選び、詳細を入力
   - グループ：名称・所属・住所が必須
   - エリア：名称・所属・営業曜日が必須
3. 右下の **【登録】** をクリック

![エリアの登録画面](/images/articles/setup/area-register.png)

## 4. アラートメールを設定する

センサーに**電圧の低下**または**通信の欠損**があると、設定したメールアドレスにお知らせが届きます（それ以外の異常は配信されません）。

| アラート | 基準 | 対応 |
| --- | --- | --- |
| 電圧の低下 | 電圧が 2.0V 以下 | 予備のセンサーと交換してください |
| 通信の欠損 | 過去1週間で欠損率 65% 以上 | 通信エリアを確認し、別のセンサーと交換してみてください。その1台だけで起きる場合は不具合が考えられます |

> [!NOTE]
> 配信先は**1代表組織につき1アドレス**です。複数人で確認する場合は、共有できるメールアドレスをご用意ください。あらかじめ、そのアドレスで**ユーザー登録**（上記2）をしておく必要があります。

1. サイドバーの **【グループ】** → **【グループ/エリア登録】** をクリック
2. **代表組織（カンパニー）** の **【登録内容変更】** をクリック
3. **【担当】** のプルダウンから配信先のユーザーを選び、**【更新】**

![アラートメールの配信先を設定する画面](/images/articles/setup/alert-mail-setting.png)

<details>
<summary>ユーザーコードで登録したユーザーを配信先にしたいとき</summary>

ユーザーコードで登録したユーザーにはメールアドレスがありません。ユーザーの詳細画面の **【登録内容変更】** から **【メールアドレス】** を追加して **【更新】** してください。

![ユーザー編集画面でメールアドレスを登録する](/images/articles/setup/user-add-email.png)

</details>

初期設定が終わったら、[顧客登録](/articles/phase2-customer-registration)に進みます。
