顧客の登録方法は2つです。どちらも登録件数に制限はありません。

| 方法 | 向いているとき |
| --- | --- |
| **[一括で登録（Excel）](#方法1-excel-で一括登録する)** | 多くの顧客をまとめて登録する。THE灯油・雪ん子などのデータを移す |
| **[1件ずつ登録（手入力）](#方法2-1件ずつ手入力で登録する)** | 顧客を少しずつ追加する |

登録済みの顧客を直すときは「[顧客・タンク・センサーの情報を編集する](/articles/edit-customer)」をご覧ください。

## 方法1 Excel で一括登録する

### Step1. テンプレートをダウンロードする

サイドバーの **【データ入出力】** → **【⇐出力・顧客情報】** → **【ダウンロード】** をクリックします。

![データ入出力画面でテンプレートをダウンロードする](/images/articles/customer/template-download.png)

### Step2. テンプレートに入力する

テンプレートには「**顧客登録**」と「**タンクタイプリスト**」の2つのシートがあります。顧客登録シートの**黄色の列は入力必須**です。

![テンプレートの「顧客登録」シート。黄色の列が入力必須](/images/articles/customer/template-columns.png)

- 必須：顧客番号・契約区分・住所・名称・エリア・タンクタイプ・タンク名
- センサーを設置する場合は「シリアルNo」も入力します
- **顧客番号**は、既存の番号があれば同じ番号を使うと管理しやすくなります。ない場合は重複しない番号を作ってください（例：1000件未満は3桁、1000件以上は4桁）
- タンクタイプは「タンクタイプリスト」シートから選びます

> [!WARNING]
> THE灯油・雪ん子など他のシステムのデータは、テンプレートの項目・並びに合わせてから取り込んでください。

### Step3. ファイルを取り込む

1. **【データ入出力】** → **【⇒入力・顧客情報】** をクリック
2. グレーの枠にファイルをドロップ（または **【ファイル選択】**）
3. **【取込】** をクリック
4. 右側の **【履歴】** に「成功」と表示されたら完了

![ファイルを取り込む画面](/images/articles/customer/import.png)

> [!NOTE]
> 取り込みは画面を閉じても続きます。ファイルの大きさにより最大10分ほどかかります。「失敗」と表示されたら、もう一度お試しください。

## 方法2 1件ずつ手入力で登録する

「顧客 → タンク → 配送 → 確認」の4ステップで登録します。**センサーはStep2（タンク）で登録します。**

![手入力での登録ステップ](/images/articles/customer/manual-steps.png)

### Step1. 顧客

サイドバーの **【顧客】** → 右上の **【顧客登録】** をクリックし、顧客情報を入力して **【次へ】**。

- **契約**：「定期配送」か「スポット配送」を選びます。定期配送は**配送頻度**（30日・60日など）を設定すると、その間隔で配送計画に自動で入ります
- **必須**：名称・顧客番号・所属エリア・住所

![顧客登録画面（Step1 顧客）](/images/articles/customer/manual-customer.png)

<details>
<summary>顧客画面の項目の説明</summary>

| 項目 | 説明 |
| --- | --- |
| 名称（必須） | 顧客の名称。THE灯油・雪ん子と連携する場合は同じ名称で登録 |
| 顧客番号（必須） | 顧客を見分ける番号。連携する場合はこの番号で紐づけるため、基幹システムと同じ番号に（文字・数字・記号可） |
| 所属エリア（必須） | エリアごとに配送計画が作られるため、定期配送では必ず設定 |
| 分類 | 集合住宅／集合住宅（メーター）／一軒家／商業施設／公共施設／工事現場／農家 |
| ポリタンク | 給油が必要なポリタンクの数 |
| 電話番号1・2 | 2つまで（ハイフン不要） |
| 住所（必須） | 配送先の住所。センサーの通信判定にも使います |

</details>

### Step2. タンク

センサーの有無とタンクの登録の有無で、入力する項目が変わります。

| パターン | 必須の項目 |
| --- | --- |
| センサーあり・タンク登録あり | センサーの有無、タンクタイプ、タンク名称、**センサーシリアル、センサー設置日** |
| センサーなし・タンク登録あり | センサーの有無、タンクタイプ、タンク名称 |
| センサーなし・タンク登録なし | 「タンク情報を登録しない」をクリック |

![タンク登録画面（Step2 タンク）](/images/articles/customer/manual-tank.png)

- **タンクタイプ**はプルダウンから選びます。一番上の枠にメーカー名や数値を入れると絞り込めます。わからないときは「[タンクタイプがわからない](/articles/tank-type)」を参照してください
- タンクタイプを選ぶと、容量と**しきい値（容量の50％）**が自動で入ります。配送したい残量に合わせて直接変えることもできます（[しきい値とは](/articles/threshold)）
- タンクが複数あるときは **【＋】** で追加し、タンク名称で見分けられるようにします（例：向かって右タンク、奥タンク）

> [!WARNING]
> センサーシリアルを間違えると、顧客を正しく管理できません。登録前に必ず確認してください。

### Step3. 配送

- **定期配送**：**【次回給油日】** に最初の配送日を設定します。以降は配送頻度に合わせて自動で配送計画に入ります
- **スポット配送**：**【指定日を追加する】** で給油指定日を追加します。未定なら空欄のまま進めます

![定期配送の次回給油日を設定する画面](/images/articles/customer/delivery-regular.png)

> [!NOTE]
> 配送はタンクが複数あっても**顧客単位**で設定します。配送計画には、しきい値に近いタンクのグラフが表示されます。

### Step4. 確認

内容を確認して登録します。顧客一覧に表示されれば完了です。

![登録内容の確認画面](/images/articles/customer/confirm.png)

## 顧客一覧の使い方

サイドバーの **【顧客】** で顧客一覧が開きます（顧客番号順）。

![顧客一覧](/images/articles/customer/customer-list.png)

- **タグ**：顧客に4色のタグを付けられます。「赤は重要」「青は〇〇さん担当」など意味を決めて使うと便利です
- **表示項目**：右上の歯車から、一覧に出す項目を選べます。項目名の横の「↓」で並べ替えできます
- **検索**：名称・電話番号・住所のフリーワード検索と、条件を指定した検索を組み合わせられます
