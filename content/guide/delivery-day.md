配送当日は、サイドバーの **【配送計画】** → **【今日】** の画面を使います。

## 1. 配送ルートを確認する

**【ルート表示】** にチェックを入れると、配送リストの順番でルートが地図に表示されます（顧客の住所が番地まで登録されている場合）。

![配送ルートの表示](/images/articles/plan/route.png)

| ボタン | 並べ替え |
| --- | --- |
| **【最適化】** | 地図上の距離が短い順。実際の走行ルートとは異なります（ナビとしては使えません） |
| **【緊急度】** | 推定残量が少ない順 |

![最適化ボタンで並べ替えた例](/images/articles/plan/route-optimize.png)

## 2. 配送リストを出力する（配送指示書）

配送員ごとにリストを確認し、地図の上の **【出力】** で Excel をダウンロードします。そのまま配送指示書として使えます。

![出力ボタン](/images/articles/plan/export.png)

![出力される Excel の例](/images/articles/plan/export-excel.png)

> [!NOTE]
> - Excel は**配送員ごと**に出力します（全員分を一度には出力できません）。
> - 並べ替えたあと、出力する前にほかの画面へ移ると、並び順が元に戻ります。

## 3. 日報を作成する（給油量の記録）

### 1件ずつ記録する

1. 「日」の画面右上の **【日報作成】** をクリック
2. 給油量を **【満タン】** か **【ℓ（リットル）】** で入力します
   - **満タン**：全配送先を一括で満タンとして記録します。給油量が不明なときや手間を省きたいときに便利です
   - **ℓ**：実際の給油量を入力します
   - 給油しなかった配送先は **【給油】** ボタンを押すと「配送スキップ」になります（次の画面で次回給油日の登録が必要です）
3. 表示された**次回給油日**を確認し、必要なら変更して **【次へ】**
4. 内容（件数・総給油量）を確認して登録します。「成功」と表示され、顧客の【履歴】タブに反映されれば完了です

![日報作成画面（給油量の入力）](/images/articles/plan/report-step1.png)

![次回給油日の確認](/images/articles/plan/report-step2.png)

> [!TIP]
> 予定になかった配送先に給油したときは、給油登録画面の **【＋】** から顧客を検索して追加できます。作成した日報は、リスト右上の **【日報修正】** から直せます。

### まとめて取り込む（Excel）

[給油情報テンプレート](/files/refuel-template.xlsx)に入力し、**【データ入出力】** → **【⇒入力・給油情報】** で日付（または期間）を指定して取り込みます。

| 項目（すべて必須） | 書き方 |
| --- | --- |
| 顧客番号 | 半角数字 |
| 配送日 | yyyy/mm/dd |
| 配送時刻 | HH:mm:ss |
| 配送量 | nnnn.nn（空欄にすると「配送スキップ」になります） |

![給油情報テンプレートの入力例](/images/articles/plan/report-template.png)

次回給油日は、最終給油日と配送頻度から自動で設定されます。給油情報を出力するときは **【⇐出力・給油情報】** を使います。
