顧客画面では、顧客の基本情報・タンク情報（センサーの有無）・給油履歴をタブで確認・編集できます。

![顧客の詳細画面（顧客・タンク・履歴のタブ）](/images/articles/edit/customer-tabs.png)

| 方法 | こんなときに |
| --- | --- |
| **[まとめて編集（Excel）](#まとめて編集するexcel)** | 配送頻度を一括で変える、センサーを一括で削除する、タンク名称をまとめて変える |
| **[1件ずつ編集（画面）](#1件ずつ編集する)** | 基本情報や備考を直す、しきい値を変える、タンクやセンサーを追加・交換する |

## まとめて編集する（Excel）

1. サイドバーの **【データ入出力】** → **【⇐出力・顧客情報】** → **【ダウンロード】**（登録中の**最新の全顧客データ**が出力されます）
2. ファイルを編集し、**ダウンロードしたものとは別の名前で保存**（元のファイルはバックアップとして残してください）
3. **【⇒入力・顧客情報】** にファイルをドロップして **【取込】**
4. **【履歴】** に「成功」と表示されたら完了

| センサーの変更 | テンプレートの「シリアルNo」 |
| --- | --- |
| 設置する | シリアルナンバーを入力 |
| 交換する | 新しいシリアルナンバーに書き換える |
| 削除する | 空欄にする |

![編集したファイルを取り込む画面](/images/articles/edit/edit-import.png)

> [!WARNING]
> 同じ名前のファイルや、途中に空欄の行があるファイルは取り込みに失敗します（[顧客を削除したいとき](/articles/delete-customer)）。

## 1件ずつ編集する

顧客一覧から顧客をクリックし、タブから編集します。

### 基本情報を変える

**【顧客】** タブ → **【登録内容変更】** → 編集して **【更新】**。

![顧客編集画面](/images/articles/edit/edit-basic.png)

### タンク情報を変える・しきい値を変える

**【タンク】** タブ → **【登録内容変更】** → 編集して **【更新】**。

![タンク情報編集画面](/images/articles/edit/edit-tank.png)

### タンクを追加する

**【タンク】** タブ → **【＋】** → センサーの有無・タンクタイプ・タンク名称を入力して **【追加】**。タンク名称は「向かって右タンク」など、見分けられる名前にしてください。

![タンク追加画面](/images/articles/edit/add-tank.png)

### タンクを削除する

**【タンク】** タブ → **【登録内容変更】** → **【削除】** → もう一度 **【削除】**。

> [!WARNING]
> センサーが付いているタンクは、**先にセンサーを撤去（下記）**してから削除してください。

### センサーを設置する

**【タンク】** タブ → **【センサー設置】** → タンクデータ画面の **【センサー設置】** → **シリアル（ナンバー）** と **設置日** を入力して **【実行】**。

![センサー設置画面](/images/articles/edit/sensor-install.png)

### センサーを交換・撤去する

**【タンク】** タブの**グラフ画像**をクリック → タンクデータ画面の **【交換】** または **【撤去】**。

- **交換**：新しいセンサーのシリアルを入力して **【実行】**（交換日は自動で今日になります）
- **撤去**：撤去するセンサーのシリアルを確認して **【撤去する】**

![センサーの交換・撤去画面](/images/articles/edit/sensor-replace.png)
