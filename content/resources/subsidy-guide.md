一般社団法人 全国石油協会の「**SSネットワーク維持・強化支援補助事業**」で、スマートオイルセンサー（灯油タンク等スマートセンサー）の購入費用の補助を受けられます。

> [!WARNING]
> 申請期限・要件は年度や都道府県によって異なります。申請の前に必ず[全国石油協会のホームページ](https://www.sekiyu.or.jp/pages/175/)の「申請手引書（設備導入等支援）」をご確認ください。

## 補助額

| 事業者の区分 | 補助額 |
| --- | --- |
| 中小企業等 | センサー購入費用の **2/3** |
| 中小企業以外 | センサー購入費用の **1/3** |

## 申請要件（主なもの）

- 申請する給油所等が、**中核SS・住民拠点SS、または BCP（事業継続計画）策定済み**であること
  - BCP は中小企業庁の「[中小企業BCP策定運用指針 第2版](https://www.chusho.meti.go.jp/bcp/download/bcppdf/bcpguide.pdf)」を踏まえて策定し、申請する給油所を位置づけておく必要があります
- 災害協力要件として、次の事項を誓約すること
  - 災害時は、災害時情報収集システムで被害状況などを報告する
  - 設備や従業員の安全を確保したうえで、可能な限り地域住民への給油を続ける
  - 災害時情報収集システムの報告訓練に協力する

> [!CAUTION]
> 申請資格は、申請時だけでなく**補助事業の実施期間中も**満たしている必要があります。満たさなくなった場合は申請取り消し・補助金の返還となることがあります。虚偽申請や重複受給が判明した場合は、交付決定の取り消しや罰則などの措置があります。

## 申請から実績報告までの流れ

1. **申請**：申請から採択まで、例年1〜2か月ほどかかります
2. **採択**：採択の通知が届いたら、お早めに当社へご連絡ください
3. **ご発注**：採択後にご発注いただきます。発注書を受け取った順に出荷・納品します
4. **納品**：出荷時に GoNOW のアカウントを作成し、納品完了時に納品書を発行します。センサーが届いたらタンクへの設置を始めてください
5. **実績報告**：補助事業（センサー設置）の完了後、**30日以内**に提出します

## 申請に必要な書類

提出書類は複数あります。早めのご準備をお願いします。

| 書類 | 入手方法 |
| --- | --- |
| ① 補助金交付申請書（様式災害対応第1号）※申請管理シートも添付 | 石油協会HPからダウンロード |
| ② （法人の場合）法人番号の写し | 国税庁 法人番号公表サイト |
| ③ 申請者の「役員等名簿」（細則様式2）※個人事業者は本人を記載 | 石油協会HPからダウンロード |
| ④ 中小企業等の場合、事業規模を確認する書類の写し（商業登記簿謄本、法人事業概況説明書 など、いずれか） | お客様でご準備 |
| ⑤ 卸売業の場合は④に加えて、卸売販売契約等 または 品質維持計画認定申請書等の写し | お客様でご準備 |
| ⑥ 中小企業等の場合、直近3年分の法人税確定申告書「別表1」と直近の「別表2」の写し | お客様でご準備 |
| ⑦ 申請給油所の BCP の写し（中核SS・住民拠点SS以外） | お客様でご準備 |
| ⑧ 申請資格要件に係る「誓約書」（細則様式1） | 石油協会HPからダウンロード |
| ⑨ 暴力団排除に関する誓約書（別紙） | 石油協会HPからダウンロード |
| ⑩ 取得財産等の管理・処分に関する誓約書（細則様式3） | 石油協会HPからダウンロード |
| ⑪ 災害発生時の対応に関する誓約書（細則様式4） | 石油協会HPからダウンロード |
| ⑫ 2業者以上の競争見積書の写し（随意契約の場合は1業者の見積書と選定理由書） | **当社でご用意します** |
| ⑬ 補助対象設備の製品仕様書（パンフレット）など | **当社でご用意します** |
| ⑭ 設置予定場所のリスト（個人情報を含まないもの。例：〇〇市 500世帯、〇〇郡〇〇町 300世帯） | お客様でご準備 |
