# 記事の書き方

このフォルダの Markdown ファイル（`.md`）が、ご利用ガイドサイトの記事になります。
GitHub の画面上で編集・追加でき、`main` ブランチに反映されるとサイトが更新されます。

## フォルダ = 記事の種類

| フォルダ | 種類 | サイトでの表示場所 |
| --- | --- | --- |
| `guide/` | ガイド | ガイド（カテゴリ別） |
| `faq/` | よくある質問 | よくある質問・ガイド（カテゴリ別） |
| `news/` | お知らせ | お知らせ・TIPS（新しい順） |
| `tips/` | TIPS | お知らせ・TIPS（新しい順） |
| `resources/` | 資料・フォーム | 資料・フォーム |

## 新しい記事を追加する

1. 追加したいフォルダを開き、「Add file」→「Create new file」
2. ファイル名を **半角の英小文字・数字・ハイフン** で付ける（例：`delivery-plan.md`）
   - ファイル名がそのまま URL になります（`/articles/delivery-plan`）
   - フォルダが違っても、同じファイル名は使えません
3. [`_template.md`](./_template.md) の中身をコピーして貼り付け、書き換える
4. 「Commit changes」で保存

## 先頭の設定（frontmatter）

ファイルの先頭の `---` で囲んだ部分に、記事の情報を書きます。

```yaml
---
タイトル: しきい値について知りたい
カテゴリ: 日々の運用
概要: しきい値は灯油切れを防ぐための限界残量です。標準は容量の50％で、タンクごとに変更できます。
キーワード: [閾値, 残量, アラート]
更新日: 2026-10-06
並び順: 2
よく見られている: true
---
```

| 項目 | 必須 | 書き方 |
| --- | --- | --- |
| タイトル | ○ | 記事のタイトル。よくある質問は「〜が知りたい」「〜がわからない」など質問の形で |
| カテゴリ | ガイド・FAQ・資料は○ | 下の一覧から選んでそのまま書く |
| 概要 | | 一覧と検索結果に出る1〜2文の説明 |
| キーワード | | 検索で見つけてほしい言い換え。`[閾値, 残量]` のように `,` 区切り |
| 更新日 | ○ | `2026-10-06` の形。内容を直したら更新する（サイトに「最終更新」として表示） |
| 公開日 | お知らせ・TIPS は○ | `2026-10-06` の形。お知らせの並び順と表示に使う |
| 外部リンク | | Canva 資料や Google フォームなど、本文を書かずにリンク先へ飛ばす記事の URL |
| 並び順 | | 同じカテゴリ内の表示順。小さいほど上（省略すると後ろ） |
| よく見られている | | `true` にすると、トップの「よく見られている質問」に出る |
| 公開 | | `false` にするとサイトに出さない（下書き） |

**カテゴリの選択肢**

- ガイド・よくある質問：`ご契約` / `センサー設置` / `GoNOW初期設定` / `操作トレーニング` / `日々の運用` / `困ったとき`
- 資料・フォーム：`ご注文・申請フォーム` / `書類・テンプレート` / `補助金` / `提供素材` / `規約・約款`

## 本文の書き方

| 書きたいもの | 書き方 |
| --- | --- |
| 見出し | `## 見出し`（小見出しは `### 小見出し`）。`##` の見出しは記事の目次に並ぶ |
| 太字 | `**太字**` |
| 箇条書き | 行頭に `- ` |
| 手順（番号付き） | 行頭に `1. ` `2. ` … |
| リンク | `[表示する文字](https://...)` |
| リンクボタン | リンクだけを1行で書く：`[タンクタイプ追加申請フォーム](https://...)` |
| YouTube 動画 | YouTube の URL のリンクだけを1行で書くと、動画が埋め込まれる |
| 画像 | `![画像の説明](/images/articles/ファイル名.png)`（画像は `public/images/articles/` に置く） |
| 表 | 下の例を参照 |
| 注意書き（オレンジ） | `> [!WARNING]` の次の行から `> ` をつけて書く |
| ポイント（青） | `> [!NOTE]` |
| 補足（緑） | `> [!TIP]` |
| 折りたたみ | `<details>` 〜 `</details>`（下の例を参照） |
| 区切り線 | `---` |

**注意書き**

```markdown
> [!WARNING]
> タンクの高さは、必ず現物を正確に計測してください。
```

**表**

```markdown
| 判定 | 電波の状態 | 設置の推奨 |
| --- | --- | --- |
| Excellent | 非常に強い | 推奨 |
| Limit | 弱い | **非推奨** |
```

**折りたたみ**（`<summary>` の行と本文の間、本文と `</details>` の間は1行空ける）

```markdown
<details>
<summary>完全削除の手順</summary>

1. サイドバー【データ入出力】をクリック
2. 【ダウンロード】ボタンをクリック

</details>
```

### 補足

- 「`**【データ入出力】**から`」のように、記号のすぐ外側に `**` があると、GitHub のプレビューでは太字にならず `**` が見えたままになります。サイト上では正しく太字になるので、そのままで問題ありません。
- 書き方に誤り（カテゴリ名の間違い、日付の形の間違いなど）があると、サイトの更新が止まり、どのファイルの何が違うかがエラーとして表示されます。

## 画像を追加する

1. `public/images/articles/` を開き、「Add file」→「Upload files」で画像をアップロード（ファイル名は半角英数字）
2. 記事に `![画像の説明](/images/articles/アップロードしたファイル名.png)` と書く

画像の説明（`[ ]` の中）は、画像が見えない方への読み上げにも使われます。「顧客一覧の画面」など、何が写っているかを書いてください。
